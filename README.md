# Git & GitHub Workshop

## Git commands

### git init 
Creates a new Git repository in the current project folder.

### git status
Showes the current status of the Git repository.

### git add
Adds files to the staging area.

### git commit -m "message"
Creates a commit with a message and saves the staged changes.

### git remote add origin URL
Connects the local repository to a remote GitHub repository.

### git remote -v
Shows the remote repository URLS.

### git branch -M main
Renames the current branch to `main`

### git push
Uploads local commits to the remote GitHub repository.

### git branch
Shows the current branches in the repository.
